## What it does

`main.py` writes exactly one word to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set): the first word that comes to mind.

## Run

```bash
python3 main.py
```

Override output directory:

```bash
MAKEFUN_OUTPUT_DIR=/tmp/ftout python3 main.py
```

## Test

